    Les postes sont définis dans les paramètres de l’application.

    LBPSOAction neutrePointErreurTerrainBanc

    En vue verticale, les colonnes Séquence, Score, Rotation, Position et Rally sont normalisées à la largeur minimale déterminée par leur en-tête le plus large. Le filtre Type d’action permet d’isoler Neutre (bleu), Erreur (rouge) ou Point (vert). Les informations Score, Rotation, Position et Rally ne sont affichées que lorsqu’elles changent. Un trait noir épais sépare le bloc Séquence / Score / Rotation / Position / Rally du bloc Joueurs / Actions. Les colonnes Joueur restent uniformes à 30 px. La ligne Position affiche S ou R sur chaque colonne. Les rotations utilisent deux gris alternés, les phases S/R des gris distincts, et la ligne Rally conserve les alternances rouge, vert et jaune. Chaque action réellement présente dans le JSON source conserve sa propre colonne. La vue « Points qui marquent uniquement » masque les actions neutres et conserve les actions décisives vertes ou rouges. Les limites de couverture du journal source sont indiquées dans le bandeau de données.

# Volley Live Capture v1.5.3 - iOS Specification

Target Safari/Home-screen PWA, reference viewport 390 x 844 CSS px.

USER GUIDE uses a direct user-initiated `window.open` so Safari permits the new PDF tab. The PDF is local to the package and precached. For deployment, replace all files, open once online, fully close Safari/PWA, then reopen. Confirm v1.5.3 and test USER GUIDE in Airplane mode.

Safari and the installed PWA may use separate localStorage. Saved teams/lineups/rotations must be created and tested in the context used courtside.

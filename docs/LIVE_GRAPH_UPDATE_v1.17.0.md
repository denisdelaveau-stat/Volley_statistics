# Spectator update 10 — implementation contract (v1.17.0)

1. Connector widths are equal because AWAY and HOME connectors occupy the same `minmax(..., 1fr)` track definition in the shared rally grid.
2. Score pills fill the central score track and retain one black half. `Rallye N` is a separate attached element.
3. Timeline headings are literal AWAY/HOME labels and are never populated from `model.awayName` or `model.homeName`.
4. HOME cards and HOME delta bars are adjacent tracks separated only by the shared responsive grid gap.
5. Order buttons and action-window selects use common control dimensions and styling.
6. LIVE GRAPH is generated by `renderScoreGraph` and `renderDeltaGraph` from normalized archive rallies. It contains no demo or hard-coded match values.

The source document is retained as `docs/update 10.docx`. Visual evidence is under `docs/screens_v1.17.0/` and automated acceptance is in `tests/spectator/test_live_graph.py`.

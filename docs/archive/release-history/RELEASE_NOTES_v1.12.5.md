# Release notes — v1.12.5

- No match loaded now produces a neutral grey empty state in Coach View and Advanced Statistics.
- Empty counters display `0`; ratios, percentages and non-calculable values display `NA`.
- No bundled or hard-coded demonstration data is loaded by default.
- The Cannes–Fréjus reference fixture is only analyzed after explicit JSON file loading (replay).
- Added explicit Match live, Charger JSON and Décharger transitions, with state reset on each transition.
- Covered Coach overview, team/rotations, players and player detail plus Statistics timeline, rotations, roster, playing time, charts and rankings.
- Removed the legend below the Coach court and reduced the orange court to a small margin below the lower player row, retaining the net, dashed front/back line, role colours and setter badge.
- Verified the compact Coach court at 390 px and 1024 px without overflow or overlap.
- Preserved COACH VIEW and ADVANCED STATISTICS on Home and retained the removal of red provenance markers.

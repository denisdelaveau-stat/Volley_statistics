# Release notes — v1.12.4

## Red demo markers removed

- Removed the special red outlines, red text overrides and red demo badges from **Coach View** and **Advanced Statistics**.
- Demo/reference sources remain identified in neutral source labels and provenance metadata.
- Match calculations and data-loading behavior are unchanged.
- Normal red semantics remain for actual errors, critical tactical status and the OH role palette.
- The **COACH VIEW** and **ADVANCED STATISTICS** buttons remain on Home.

## Preserved baseline

The v1.12.3 provenance logic, v1.12.1 capture layout, compact player strip, fixed controls, scoring, rotation logic, History, Undo, compact libero bench, same-position substitutions, pastel role palette and offline PWA behavior are retained.

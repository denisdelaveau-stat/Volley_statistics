# Release notes — v1.12.2

This release makes the data origin of every Advanced Statistics and Coach View indicator visible.

- Values computed from JSON records keep the normal theme.
- Indicators based on inferred Capture v1 context are red.
- App-defined qualitative thresholds receive a red non-JSON marker.
- The Coach player presence status is now computed, not hard-coded.
- Existing Capture, Home, Coach, Advanced Statistics and offline-PWA features are retained.

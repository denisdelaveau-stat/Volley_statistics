# Install or update Volley Live Capture v1.6.10 on iPhone

1. Deploy the complete v1.6.10 folder, including `sw.js`, `manifest.webmanifest` and every file in `icons/`.
2. Confirm the service-worker cache ID is `volley-live-capture-v1.6.10`.
3. In Safari, open the deployed application online once.
4. If the previous light-bordered icon remains, remove the existing Home-screen shortcut. iOS caches touch icons independently from page content.
5. Use Share → Add to Home Screen, then launch from the new icon.
6. Verify the Home screen shows the navy-to-edge icon and the app Home screen shows `v1.6.10`.
7. Fully close and reopen the app to verify offline relaunch and saved-match persistence.

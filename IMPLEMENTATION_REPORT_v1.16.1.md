# Implementation report — Volley Live Capture v1.16.1

## Baseline and scope
This release is built from the complete v1.16.0 package. It implements every instruction in `time line2.docx` in the archive spectator LIVE TIMELINE while preserving unrelated application behavior.

## Implemented requirements
1. **Timeline not centered:** the desktop row/title grid gives the AWAY side 1.35 flexible units and the HOME side 0.65, placing the score spine at approximately 63% of the board width.
2. **AWAY close to the left edge:** the AWAY delta lane begins at the timeline's 12 px content inset. A 100% delta bar shares the same left coordinate.
3. **Smallest practical HOME cell:** `.event-card` uses `width: max-content` with `max-width: 100%`; `.event-copy` is content-sized with a 230 px safety cap.
4. **Balanced side spacing:** the card uses `padding: 10px 14px`; browser geometry measures equal left and right content insets.
5. **Responsive score line:** the cyan line is generated by `.score-node::before`, guaranteeing alignment with each score pill despite the asymmetric grid.

# Volley Live Capture v1.5.3 release updater

This package upgrades the complete v1.5.0 application source without dropping saved teams, starting seven, rotations or ROTATE +1.

Run:
`python apply_v1_5_3.py /path/to/VolleyLiveCapture_v1.5.0`

The target folder becomes the complete v1.5.3 runtime package. The updater copies `USER_GUIDE.md` and `user_guide.pdf`, keeps `index_before_v1.5.3.html`, and updates `sw.js`.

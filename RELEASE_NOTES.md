# Volley Live Capture v1.6.8 — Release Notes

This presentation-only release corrects two v1.6.7 visual choices:

- The compact volleyball net no longer has a dark fill. Its background is transparent so the page background remains visible; mesh, tape, posts, antennas and proportions are retained.
- Player silhouette icons are removed from the six Advanced action labels.
- Attack/Block, Defence/Reception and Service/Set label colours remain unchanged.
- Rare legal actions remain lighter, and action names—including `Reception`—are not truncated.

The screenshot PDF, English Word UI specification and automated tests are updated. Existing format-version-1 match files remain compatible.
